### 1.2 双层设计标尺（Core Norm Target vs Wishlist Extension Target）

审计矩阵严格区分 **Core 正式语言契约** 与 **Wishlist 完整演进蓝图**，绝不混用：

1. **Core 正式标尺（Core Norm Target）**：以 [AGENTS.md](file:///home/fin/luna/AGENTS.md) §1/§3/§5 及现行 `docs/` 为唯一规范权威（严格排除 `2026-5` 前 `proposal_trace/`、`docs/OLD-2024/`、`prompt.fl` 与教学性 `flurry_tutorial/`）：
   - **六内置包与 Prelude 边界**（[builtin-packages.md](file:///home/fin/luna/docs/code-organization/builtin-packages.md)、[AGENTS.md](file:///home/fin/luna/AGENTS.md) §3/§5）：严格只有 6 个内置包（`math` 归 `builtin.prelude`，不立第 7 包；`str` 归 `builtin`，`String` 归 `std`；内存模块名为 `mem`）；除 `std` 外其余 5 包的 `prelude` 默认自动导入（自排除 + 声明身份去重）；6 包享有对 builtin 类型的孤儿规则豁免，且所有 `.symbol'builtin` 必须隔离在集中绑定层。
   - **原生可选与错误结果，严禁 `Option`/`Result`**（[AGENTS.md](file:///home/fin/luna/AGENTS.md) §5、[error-handling.md](file:///home/fin/luna/docs/algebraic-effect-and-delimited-continuation/error-handling.md)）：仅用原生 `?T` 与 `!E T` / `![...] T`；错误类型用 `PascalCaseErr`、错误变体 `PascalCase`、普通 enum 变体 `snake_case`。
   - **双阶段同名 Trait 规则与无指针 Comptime**（[AGENTS.md](file:///home/fin/luna/AGENTS.md) §3/§5、[the-comptime-phases-of-traits.md](file:///home/fin/luna/docs/comptime/the-comptime-phases-of-traits.md)）：runtime 与 comptime 同名方法分别置入普通 `trait` 与 `pure comptime trait`（禁止 `comptime_` 前缀或混用单个 trait 凑双相）；comptime `self` 采用值引用语义，禁止 `*self`、`*List<T>`、`.ref`、`.*`。
   - **Normal-Form 不展开、单一全称 `Once`、属性与正交性**（[AGENTS.md](file:///home/fin/luna/AGENTS.md) §5、[official-attribute-keys.md](file:///home/fin/luna/docs/comptime/official-attribute-keys.md)）：`Tuple<...Es: meta.List<Type>>` 等通过通用 NF 规则，不为具体库定义增加编译器特判；仅保留唯一全称 `impl Once for T where T {}`；所有官方属性通过 `^attrs.*` 封装 `__flurry_*` 键（禁止裸键与 `.id expr`）；`verification` 高级能力在 `AGENTS.md` §3 中明确暂缓，并严格禁止程序状态混入 PTC。
   - **单一 `luna` CLI**（[AGENTS.md](file:///home/fin/luna/AGENTS.md) §1）：取消独立 `anar`，`build` 服务于 `luna` 统一构建上下文。
2. **Wishlist 扩展标尺（Wishlist Target）**：以 [tmp/wishlist/00](file:///home/fin/luna/tmp/wishlist/00-index-and-roadmap.md)、[01](file:///home/fin/luna/tmp/wishlist/01-syntax-protocols-and-operators.md)、[02](file:///home/fin/luna/tmp/wishlist/02-pattern-matching-and-views.md)、[04](file:///home/fin/luna/tmp/wishlist/04-builtin-types-math-iterators-fmt.md)、[05](file:///home/fin/luna/tmp/wishlist/05-meta-cmtt-macros-reflection.md)、[06](file:///home/fin/luna/tmp/wishlist/06-attrs-build-pipeline-projection.md)、[09](file:///home/fin/luna/tmp/wishlist/09-verification-synthesis-and-tensors.md) 及 [10](file:///home/fin/luna/tmp/wishlist/10-official-protocol-packages-and-boundary.md) 为长期生态完整度标尺——包括全量原语固有方法、14 组 `Type.predicates.*`、全量 CMTT `meta.code` 对象、`__flurry_align`（Silver P1-5）、匿名记录 `Ps` 反射（Silver P0-2）、`bounded_stack_bytes`（Silver P0-3）、`pipeline-projection` 协议栈及 `build` 完整 DAG 接口，同时严守 `10` 三层反膨胀黑名单（Tier 2/3 不得污染 Tier 1 五包）。

## 4. 关键缺口深度剖析（含源码证据）

### 4.1 依赖拓扑失真：Sysroot 全连通 `K_6` 掩盖了 `builtin -> {meta, attrs}` 反向依赖

按 [builtin-packages.md](file:///home/fin/luna/docs/code-organization/builtin-packages.md) 与六包分层架构，`builtin` 必须位于依赖 DAG 最底层，零反向依赖 `meta` 或 `attrs`。但实盘扫描显示当前 `library/builtin/` 存在 **4 处直接向上导入**：

1. [tuple.fl:6](file:///home/fin/luna/library/builtin/types/tuple.fl#L6)：`pub const Tuple: pure comptime fn<...Es: meta.List<Type>> -> Type = .Tuple'builtin;` 直接引用 `meta.List`；
2. [display.fl:1-5, 43](file:///home/fin/luna/library/builtin/protocols/formatting/display.fl#L1-L45)：`use meta.{isize_representation as ..., str_from_char, usize_representation as ...}` 与 `^attrs.comptime_phase`；
3. [options.fl:2](file:///home/fin/luna/library/builtin/protocols/formatting/options.fl#L2)：`use meta.{ComptimeTextBytes, ComptimeTryFrom, List, str_from_char}`；
4. [radix.fl:1](file:///home/fin/luna/library/builtin/protocols/formatting/radix.fl#L1)：`use meta.ComptimeTextBytes;`。

**为什么这在当前 `--sysroot library` 下还能编译？** 根因在 [frontend.rs:664-675](file:///home/fin/luna/compiler/luna/src/frontend.rs#L664-L675)：

```rust
    for requester in &packages {
        for provider in packages.iter().skip(1) {
            if requester.resolution_id != provider.resolution_id {
                dependencies.push(resolve::DependencyEdge {
                    requester: requester.resolution_id,
                    alias: provider.name.clone(),
                    provider: provider.resolution_id,
                });
            }
        }
    }
```

编译器把 6 个 sysroot 包连成了一个全连通有向图 $K_6$（`builtin <-> meta <-> attrs <-> build <-> std <-> verification`），并把 5 个非 `std` prelude 相互注入。后果已经显现在测试基础设施中：
- [library_check.py:44-47](file:///home/fin/luna/development/library_check.py#L44-L47)（`--stage meta-values`）与 [meta_source.rs:6-8](file:///home/fin/luna/compiler/luna/tests/support/meta_source.rs#L6-L8) 无法加载完整的 `library/builtin/lib.fl` 来测试 `meta`，只能拆出 `library/builtin/primitives.fl` 拼装假 `builtin` 模块；
- [library_protocols.rs:32-35](file:///home/fin/luna/compiler/luna/tests/library_protocols.rs#L32-L35) 与 [library.rs:3-5](file:///home/fin/luna/compiler/luna/tests/support/library.rs#L3-L5) 必须用 `with_attrs(...)` 给独立 `builtin` 用例注入 `mod attrs { ... }` 才能过编译。

**架构根治**：按 `AGENTS.md §3` 双阶段拆分 `Display`（将 `comptime_fmt` 与 `options` 编译期解析/`format_*_comptime` 移入 `meta` 的 `ComptimeDisplay` `pure comptime trait`），消除 `builtin` 对 `attrs.comptime_phase` 与 `meta.ComptimeTextBytes` 的反向依赖；同时将 `meta.List` 底层绑定或 `Tuple` 参数边界梳理到严格 DAG（`builtin <- meta <- attrs <- build <- {std, verification}`），并在 `frontend.rs` 移除 `builtin -> {meta, attrs, build, std, verification}` 的非法依赖边。

### 4.2 `builtin` 协议签名偏差矩阵（`ops` / `cmp` / `hash` / `conversion` / `Display`）

五份最基础的语言接入协议（`library/language-items.conf` 绑定点）中，有 **四族** 在现有源码中存在破坏仿射所有权或违背双阶段规范的设计债：

1. **`Index` 的所有权/悬垂悖论与 `IndexMut` 接线缺口**（[ops.fl:82-90](file:///home/fin/luna/library/builtin/protocols/ops.fl#L82-L90)）：
   ```flurry
   pub trait Index where Idx {
       assoc Output: Type;

       fn index(self, idx: Idx) -> *Output;
   }

   pub trait IndexMut :- Index<Idx> where Idx {
       fn index_mut(*self, idx: Idx) -> *Self.as(Index<Idx>).Output;
   }
   ```
   `Index.index`（L85）**按值消费 `self`** 却返回内部元素指针 `*Output`——值一结束调用即销毁，`*Output` 逻辑上必然悬垂；虽然 `IndexMut.index_mut`（L89）已正确借用 `*self`，但其父 trait 约束及默认返指来源 `Self.as(Index<Idx>).Output` 仍与按值 `Index` 耦合，且 `language-items.conf:1-22` 缺失 `index-mut-protocol`（[type_constructors.rs:563](file:///home/fin/luna/compiler/luna/src/protocols/type_constructors.rs#L563) 亦无 `IndexMut` 槽位）。正确设计必须将 `Index.index` 改为接收 `*self`（借助可达性/借用约束返回 `*Output`）并同步接通 `IndexMut` 与 `places.rs` 下标写回。
2. **`Eq` / `Ord` / `Hash` 按值消费接收者**（[comparison.fl:6-14](file:///home/fin/luna/library/builtin/numeric/comparison.fl#L6-L14)、[traits.fl:23-25](file:///home/fin/luna/library/builtin/protocols/traits.fl#L23-L25)）：
   `fn eq(self, other: Self) -> bool`、`fn cmp(self, other: Self) -> Order`、`fn hash(self) -> u64` 全部按值传参。在 Flurry 默认仿射（`Once`）模型下，这意味着比较或哈希两个拥有堆内存的 `String` / `Vec`（哪怕是 `Copy` 之外的值）必须先 `.clone()` 或消费掉对象；且 `Hash` 硬编码单态 `u64` 而非通用 `Hasher`/`BuildHasher` 流式写入器。
3. **`TryFrom` / `TryInto` 错误返回 `?T` 而非 `!Err T`**（[conversion.fl:10-16](file:///home/fin/luna/library/builtin/protocols/conversion.fl#L10-L16)、[conversions.fl:6-11](file:///home/fin/luna/library/meta/numeric/conversions.fl#L6-L11)）：
   ```flurry
   pub trait TryInto where Target {
       fn try_into(self) -> ?Target;
   }
   ```
   按 [error-handling.md](file:///home/fin/luna/docs/algebraic-effect-and-delimited-continuation/error-handling.md) 与 `AGENTS.md §5`，可失败转换必须声明 `assoc Err: Type;` 并返回原生错误结果 `!Err Target` / `!Err Self`（例如 `TryFromIntErr`），不可把有失败原因的转换降格为无信息 `?T`（`?T` 仅用于合法可空查找）。同样，`builtin/protocols/formatting/writer.fl:25-28, 39-42` 在 `write_raw_bytes` / `write_str` 中遇到 `checked_add_usize(...)` 或 `str_byte(...)` 返回 `null` 时使用 `null => break` 静默丢弃字节返回成功，违背 `ByteWriter` 的不丢字节错误处理契约。
4. **`Display` 违背双阶段同名 Trait 规范**（[display.fl:38-45](file:///home/fin/luna/library/builtin/protocols/formatting/display.fl#L38-L45)）：
   `OptionalOps`/`ComptimeOptionalOps`、`ErrorResultOps`/`ComptimeErrorResultOps`、`TextBytes`/`ComptimeTextBytes`、`Eq`/`ComptimeEq`、`Ord`/`ComptimeOrd`、`Hash`/`ComptimeHash` 全部已经按 `AGENTS.md §3` 升级为独立 `pure comptime trait` + **同名无前缀**方法；唯独 `Display` 仍把 runtime `fn fmt(*self, output: *W, ...)` 和 `^attrs.comptime_phase comptime fn comptime_fmt(self, ...)` 绑死在同一个 trait 中，不仅造成 `comptime_` 前缀违规与 `builtin -> {meta, attrs}` 依赖环，还迫使 `comptime impl Display` 实现者悬空 runtime 相。
