## 已确认并写入的规则

| 项目 | 写入内容 |
|---|---|
| B1 | BitVec<N> 是 Copy 值，宽度 comptime、内容可 runtime；支持零宽度 |
| B2 | 低位编号从零开始，拼接左高右低；数值位序与存储字节序分开 |
| B3 | 字面量、拼接、同宽逐位操作、比较、索引、定宽切片；双侧各求值一次 |
| B4 | 读取形成值，直接位置投影可以回写；重叠更新先取得右侧，保留实际访问与责任 |
| B5 | 扩宽高端补零；窄化先切片；一般类型同宽位转换承担 unsafe 构造契约 |
| B6 | 未定义填充不能自动变成普通比特；相同表示不创造访问资格、环境或拥有责任 |
| B7 | 合法映射有基准降码；预算、Unknown 与无优化候选不改变合法性 |
