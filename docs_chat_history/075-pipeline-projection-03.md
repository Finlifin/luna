## Intrinsic 的具体写法

下面 Inst 是教学用指令族，fma 与 barrier 沿用你的命名。只有明确支持这些操作的 pipeline 才能接受它们；枚举声明本身不实现指令。

```flurry
^intrinsic_enum
enum Inst {
    fma,
    barrier,
}

unsafe fn fused_multiply_add(a: f32, b: f32, c: f32) -> f32 {
    Inst.fma'intrinsic(a, b, c).as(f32)
}

unsafe fn wait_group() {
    Inst.barrier'intrinsic(0u16);
}
```

对照下面的独立反例：

```flurry
unsafe fn missing_result_type(a: f32, b: f32, c: f32) -> f32 {
    let result: f32 = Inst.fma'intrinsic(a, b, c);
    result
}
```

左侧 f32 不会给 intrinsic 补上结果类型；该调用按 void 检查，不能靠外围的 f32 要求取得 fma 的值。实例化后请求的输出类型是否受到该操作支持，由 pipeline 检查；写下 as 也不自动证明对应机器表示存在。

向量 load/add 的中间量同样各自给出输出类型。具体向量类型采用目标库实际提供的类型，不在语言文档里临时发明一个标准库名称。
