# 基本数据类型

基本数据类型是 Flurry 内建的最原子化的类型，所有复合类型都由它们构成。

## 整数类型

| 类型 | 宽度 | 备注 |
|------|------|------|
| `i8` / `u8` | 8 位 | `u8` 常用于表示字节 |
| `i16` / `u16` | 16 位 | |
| `i32` / `u32` | 32 位 | 无后缀整数字面量在推导失败时按 `i32` 处理 |
| `i64` / `u64` | 64 位 | |
| `i128` / `u128` | 128 位 | |
| `isize` / `usize` | 平台指针宽度 | `usize` 是数组索引、集合大小的首选类型 |

## 浮点类型

| 类型 | 标准 |
|------|------|
| `f32` | IEEE 754 单精度 |
| `f64` | IEEE 754 双精度 |

特殊值通过类型关联访问，如 `f64.NaN`、`f64.Infinity`。

## 布尔类型

`bool`：只有 `true` 和 `false` 两个值，用于条件判断和逻辑运算（`and`、`or`、`not`）。

## 字符类型

`char`：表示一个 Unicode 标量值，通常占 32 位。

## `void`

`void` 是单元类型，只有一个值 `()`。用于表示函数不返回有意义的值，可以省略 `-> void`。

## 指针类型

`*T` 指向类型 `T` 的值，位宽与 `usize` 相同。取址、解引用和字段指针传播见[指针](../resource-management/pointers.md)与[接收者适配](../type/receiver-adaptation.md)；实际操作还须满足相应程序契约。

## 宇宙、代理与 splice

Flurry 区分编译期宇宙与运行时宇宙（见 [跨阶段值传递](../comptime/quoting-and-splicing.md)）。类型相对于这两个宇宙，常见有两类情形：

1. **仅编译期**：类型只在编译期宇宙中存在。其值进入运行时上下文时，按该类型的 **splice** 规则落到某个**运行时类型**（代理不必与源类型同名）。
2. **两宇宙同名**：同一名字在两个宇宙中都有对应物；运行时侧称为 **proxy**。对此类类型，splice 嵌入运行时时，得到的是**同名 proxy** 上的值。

字面量、comptime 计算结果等进入运行时上下文，是 splice 的常见场景。具体 splice 目标、定宽选择等由类型规则与推导决定，不在此逐条展开。

**举例**（不是为这些名字单独立的规则）：

| 类型 | 情形 | 备注 |
|------|------|------|
| `Integer` | 仅编译期 | 任意精度；整数字面量的类型 |
| `Float` | 仅编译期 | 浮点 / 科学计数法字面量的类型 |
| `str` | 两宇宙同名 | 字符串 |
| `Symbol` | 两宇宙同名 | 符号（`.identifier`） |
| `Type` | 仅编译期（类型层） | 类型的类型；泛型与反射 |

无后缀数值字面量在推导失败时按 `i32` / `f64` 处理；也可用后缀转到其它定宽类型。见 [字面量](./literals.md)。

上述名字一般经 `std.prelude.*` 直接可见，也可写完整模块路径。

## 类型推断

Flurry 支持局部类型推断：`let` 绑定中可以省略类型注解，编译器从初始化表达式推断；函数签名和结构体字段通常需要显式标注。

```flurry
let x = 42;
let y: f64 = 3.14;
let s: str = "hi";
```
